# PDF Splitter (PDF分割Webアプリ)

ブラウザ上で完結する、軽量で安全なPDF分割Webアプリケーションです。  
サーバーへのファイルアップロードは一切行われず、お使いの端末（クライアントサイド）のブラウザ内で高速にPDFを分割処理します。

---

## 🌟 主な機能

- **4分割 (2×2 グリッド)**
  - 1ページを「左上・右上・左下・右下」の4ページに均等分割。ポスター印刷や拡大印刷用データの作成に便利です。
- **2分割 (左右 / 縦割り)**
  - 1ページを中央で「左・右」の2ページに分割。見開きPDFの分割や、横向き2枚綴りの資料を1ページずつに切り分けるのに最適です。
- **連続処理対応**
  - 分割・保存後も、リロード不要でそのまま別のパターンを選んですぐに再分割が可能です。
- **安心・安全設計 (完全オフライン対応)**
  - 処理はすべてブラウザ上のJavaScript (`pdf-lib`) で行われるため、機密情報が含まれるPDFでも外部サーバーに送信される心配がありません。

---

## 🚀 使い方

1. `index.html` を任意のWebブラウザ（Google Chrome, Safari, Microsoft Edgeなど）で開きます。
2. 分割したいPDFファイルをドラッグ＆ドロップ（またはクリックして選択）します。
3. **「4分割」** または **「2分割 (左右)」** を選択します。
4. **「分割を実行する」** ボタンをクリックします。
5. 処理が完了したら **「分割済みPDFを保存」** をクリックしてダウンロードします。
